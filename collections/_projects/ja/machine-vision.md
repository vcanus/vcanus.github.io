## Gidel の FPGA ベースマシンビジョンソリューション — 韓国では VCANUS が提供

**Gidel**（イスラエル）は、30年以上にわたり FPGA ベースのマシンビジョンに注力してきたグローバルスペシャリストです。製品ポートフォリオは、**PCIe フレームグラバー**、**FPGA + NVIDIA Jetson 統合エッジコンピュータ**、**カメラシミュレーター**、**画像処理 IP コアライブラリ**と、ビジョンパイプライン全体をカバーしています。

**VCANUS は Gidel の韓国正規代理店**として、産業用ビジョン、UAV、防衛、医療、スポーツ AR、ATE 分野の韓国のお客様に、製品供給、技術サポート、カスタム統合サービスを提供しています。

**Gidel 製品ラインの主な特長**

- **FPGA ベースの決定論的処理** — ハードウェアレベルのリアルタイム性能、OS ジッタなし、Zero Frame Loss
- **マルチカメラインターフェース** — GigE Vision · CoaXPress-12 · Camera Link を単一プラットフォームでサポート
- **FPGA によるリアルタイム圧縮** — JPEG · Lossless · Quality+ · HDR IP コア
- **マルチカメラ同期（InfiniVision）** — 100台以上のカメラをナノ秒レベルで同期
- **AI エッジコンピューティングとの統合** — FPGA + NVIDIA Jetson 複合エッジコンピュータ
- **開発ツールとカスタマイズ** — ProcVision Suite · GIL · CamSim · SkyBoost SDK

## フレームグラバー — HawkEye シリーズ

**PCIe スロット搭載型フレームグラバー。** 産業用カメラインターフェースを1枚のカードに統合し、圧縮、HDR、デベイヤーなどの FPGA オンボード画像処理を備えています。

**主な機能**
- **マルチインターフェースのラインナップ** — GigE Vision · CoaXPress-12 · Camera Link モデル
- **Zero Frame Loss · CPU 使用率ゼロ** — ハードウェア DMA による直接転送
- **FPGA オンボード処理** — リアルタイム画像処理、圧縮、HDR
- **PoCXP / PoCL** — 電源とデータを同一ケーブルで伝送し、配線を簡素化
- **InfiniVision 対応** — マルチカメラ同期の拡張

## FantoVision — IoT エッジコンピュータ（FPGA + Jetson）

**FPGA ベースの画像取得と NVIDIA Jetson による AI 推論を、1台のコンパクトな筐体に統合したエッジコンピュータです。** 画像の取得・圧縮・前処理・AI 推論をサーバーなしで現場で完結できるため、SWaP（サイズ・重量・電力）の制約が重要な **UAV / ドローン、産業用ロボット、医療機器、組込みビジョンシステム**に最適です。

**主な機能**
- **FPGA + NVIDIA Jetson** 統合エッジコンピュータ（Xavier NX · Orin NX を選択可能）
- **コンパクトな筐体** — 約 13.4 × 9 × 6 cm、約 750 g
- **FPGA オンボード処理** — 圧縮、HDR、画像補正
- **CUDA ベースの AI 推論** — 画像取得と推論を同時実行
- **耐環境オプション** — I オプション（拡張温度範囲）、R オプション（振動 / 粉塵 / 湿度対策）
- 屋外、防衛、航空宇宙での導入に適合

## 画像処理ライブラリ — GIL と開発ツール

**Gidel ハードウェアに最適化された統合開発ツールチェーンです。** 検証済みの IP コアを再利用して信頼性を確保し、FPGA の深い専門知識がなくてもカスタムビジョンアルゴリズムを構築できます。

**GIL（Gidel Imaging Library）**
- 30年にわたる FPGA 開発経験に基づくビジョン・画像処理 IP コアライブラリ
- **CPU オフロード** — 重い演算を FPGA が担い、システムリソースを解放
- **多様な IP コア** — システム（Multiport · MultiFIFO）、カメラ I/F、画像処理（デベイヤー · ヒストグラム · モルフォロジー）、デバッグ
- **圧縮 IP コア** — JPEG · Lossless · Quality+
- **FPGA 仮想化** — 複数のアプリケーションで FPGA を同時に共有
- **GenICam 標準に対応**

**ProcVision Suite**
- C/C++ ベースのカスタム FPGA IP コアの開発とコンパイル
- FPGA の専門家でなくてもアルゴリズムを実装可能 → 開発を迅速化
- 迅速な OEM/ODM カスタマイズ

**SkyBoost SDK**
- 高速な RAW → JPEG 変換 API
- ハードウェアアクセラレーションにより、ソフトウェア処理より高速
