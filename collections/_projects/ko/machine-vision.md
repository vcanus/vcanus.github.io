## Gidel 사 FPGA 기반 머신비전 솔루션 — VCANUS가 한국에서 공급합니다

**Gidel** (이스라엘)은 30년 이상 FPGA 기반 머신비전 분야에 집중해 온 글로벌 전문 기업으로, **PCIe 프레임 그래버**, **FPGA + NVIDIA Jetson 통합 엣지 컴퓨터**, **카메라 시뮬레이터**, **이미징 IP 코어 라이브러리**까지 비전 파이프라인 전 영역을 아우르는 제품군을 제공합니다.

**VCANUS는 Gidel의 한국 공식 총판**으로서, 산업비전 · UAV · 방산 · 의료 · 스포츠 AR · ATE 등 국내 다양한 분야의 고객사를 대상으로 제품 공급, 기술 지원, 커스텀 통합 서비스를 제공합니다.

**Gidel 제품군의 특징**

- **FPGA 기반 결정론적 처리** — 하드웨어 수준 실시간 성능, OS 지터 없음, Zero Frame Loss
- **다중 카메라 인터페이스** — GigE Vision · CoaXPress-12 · Camera Link 단일 플랫폼 지원
- **실시간 FPGA 압축** — JPEG · Lossless · Quality+ · HDR IP 코어
- **다중 카메라 동기화 (InfiniVision)** — 100대 이상 카메라 나노초 수준 동기화
- **AI 엣지 컴퓨팅 통합** — FPGA + NVIDIA Jetson 결합 엣지 컴퓨터
- **개발 도구 & 커스터마이징** — ProcVision Suite · GIL · CamSim · SkyBoost SDK

## Frame Grabber — HawkEye 시리즈

**PCIe 슬롯 장착형 프레임 그래버.** 산업용 카메라 인터페이스를 단일 카드에서 통합 지원하며, FPGA 온보드에서 압축·HDR·디베이어 등 영상 처리를 직접 수행합니다.

**핵심 특징**
- **다중 인터페이스** — GigE Vision · CoaXPress-12 · Camera Link 모델 라인업
- **Zero Frame Loss · Zero CPU 사용** — 하드웨어 DMA 직접 전송
- **FPGA 온보드 처리** — 실시간 이미지 처리, 압축, HDR
- **PoCXP / PoCL** — 카메라 전원·데이터 케이블 통합으로 배선 단순화
- **InfiniVision 호환** — 다중 카메라 동기화 확장

## FantoVision — IoT용 엣지 컴퓨터 (FPGA + Jetson)

**FPGA 기반 영상 취득과 NVIDIA Jetson AI 추론을 단일 컴팩트 장치에 통합한 엣지 컴퓨터.** 서버 없이 현장에서 영상 취득·압축·전처리·AI 추론을 완결할 수 있어, **UAV · 드론 · 산업용 로봇 · 의료기기 · 임베디드 비전** 등 SWaP(크기·무게·전력) 제약이 있는 환경에 최적화되어 있습니다.

**핵심 특징**
- **FPGA + NVIDIA Jetson** 통합 엣지 컴퓨터 (Xavier NX · Orin NX 옵션)
- **초소형 폼팩터** — 약 13.4 × 9 × 6 cm, 약 750 g
- **FPGA 온보드 처리** — 압축, HDR, 이미지 향상
- **CUDA 기반 AI 추론** — 영상 취득과 동시에 추론 처리
- **내환경 옵션** — I 옵션 (광온도 범위), R 옵션 (방진·방습)
- 옥외·군수·항공 등 가혹 환경 배치 지원

## Camera Simulator — CamSim

**물리적 카메라 없이 프레임 그래버 및 영상 파이프라인 전체를 검증할 수 있는 PCIe 기반 카메라 시뮬레이터.** 결정론적 테스트로 알고리즘 개발과 다중 카메라 파이프라인 재현이 가능합니다.

**모델 라인업**
- **CamSim-CL** — Camera Link (Deca / Full / Medium / Base 지원)
- **CamSim-X** — CoaXPress 다채널 지원

**활용 분야**
- 알고리즘 개발 · 검증
- 다중 카메라 파이프라인 재현
- 결정론적 테스트로 버그 원인 특정
- 하드웨어 없는 사전 개발 · 테스트

## Imaging Library — GIL & 개발 도구

**Gidel 하드웨어에 특화된 통합 개발 도구 생태계.** 검증된 IP 코어 재사용으로 신뢰성을 확보하고, 비 FPGA 전문가도 커스텀 비전 알고리즘을 개발할 수 있습니다.

**GIL (Gidel Imaging Library)**
- 30년 FPGA 개발 경험 기반 비전 · 이미징 IP 코어 라이브러리
- **CPU 오프로딩** — FPGA가 고부하 연산 처리, 시스템 자원 절약
- **다양한 IP 코어** — 시스템(Multiport · MultiFIFO), 카메라 I/F, 이미지 처리(디베이어 · 히스토그램 · 모폴로지), 디버그
- **압축 IP 코어** — JPEG · Lossless · Quality+
- **FPGA 가상화** — 다수 애플리케이션이 FPGA를 동시 공유
- **GenICam 표준 지원**

**ProcVision Suite**
- C/C++ 기반 커스텀 FPGA IP 코어 개발 · 컴파일
- 비 FPGA 전문가도 알고리즘 구현 가능 → 개발 기간 단축
- OEM/ODM 고객 맞춤형 솔루션 신속 지원

**SkyBoost SDK**
- 고속 RAW → JPEG API
- 소프트웨어 대비 빠른 하드웨어 가속
